한 기사만을 위한 **흑백 신문 스케치** 장면 묘사를 작성합니다.

입력:
- **title**: 기사 제목
- **summary**: 기사 요약(없으면 제목만 사용)

작성 원칙:
- 이미지 생성 모델에 넘길 **영어 장면 설명 1~2문장**만 작성하세요.
- **이 기사만의 주제**를 은유·상징으로 그립니다. 제목·요약에 나온 사물·장소·정책을 반영하세요.
- 모든 기사에 똑같은 충전소·전력망 풍경을 쓰지 마세요. 기사가 배터리면 배터리, 법안이면 문서와 도장, 공장이면 공장 실루엣처럼 다르게.
- 스타일 힌트는 시스템에서 붙이므로 JSON에는 장면만 담으세요.
- 실제 인물 얼굴, 회사 로고, 브랜드명, 읽을 수 있는 글자·표지판 금지.
- 폭력·선정적 묘사 금지.

유효한 JSON만 응답:
{
  "scene": "string — English scene description for a newspaper editorial sketch of THIS story"
}
